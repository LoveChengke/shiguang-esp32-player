你好，拾光。

这块屏幕运行从 src/main.cpp、src/reader.cpp 和 PocketCore 编译得到的 WebAssembly。显示、按键、SD、NVS 和音频接口由浏览器适配。

  • 短按上 / 下：选择、翻页；播放页直接调音量。
  • 短按 OK：确认、暂停；阅读时打开进度 / 字号菜单，确认后上下调整，再确认应用。
  • 左右：音乐后退 / 前进约 10 秒；长按左右切歌。阅读时每次跳转 5%。
  • 音乐库长按 OK：加入 / 移出自选播放列表。在列表中选歌即按自选顺序循环。
  • 长按上 / 下：音量加 / 减。
  • 长按 OK 或模式：播放 / 暂停背景音乐。
  • 模式：音乐与阅读切换；长按返回：保存并回主页。

通过「开发模拟器.cmd」启动后，修改固件源码并保存，会自动重新编译并重启模拟器。错误会显示在右侧构建状态。通过「打开模拟器.cmd」打开的是最近一次构建，不会监视源码。

导入的媒体只保存在此浏览器中；导入后自动重启并由固件重新扫描虚拟 SD 卡。TXT 可选择 GBK / UTF-16，导入时转为 UTF-8。

这是固件源码级主机模拟器。中文字形由系统字体代替，音频由浏览器代替 ESP8266Audio/I2S；不模拟 Xtensa 指令、FreeRTOS 调度、真实内存或电气外设。新增硬件 API 时需扩充 simulator/hal。
